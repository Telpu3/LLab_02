# Лабораторная работа №2 — Вариант 20

## Совершенные числа

Три задачи на Windows Forms:  
1. Проверить, совершенное ли число  
2. Найти все совершенные числа до N  
3. Нарисовать делители прямоугольниками (ширина пропорциональна делителю)

---

## Как запустить

Открыть `2.sln` в Visual Studio → F5

---

## Что внутри

- `Form1.cs` — кнопки, поля, список, картинка
- `PerfectNumberLogic.cs` — вся математика (вынесено отдельно)
- `TestProject1` — 23 юнит-теста (MSTest)

---

## Как это работает

**Задача 1**  
Введите число → нажмите «Проверить» → выводится «совершенное» или «нет»

**Задача 2**  
Введите N → ищутся все совершенные числа от 2 до N → выводятся в ListBox с делителями

**Задача 3**  
Вводишь число → рисуются цветные прямоугольники, ширина = делитель / сумма делителей * ширину поля
## Технологии

- C# + Windows Forms
- .NET 10.0
- MSTest
